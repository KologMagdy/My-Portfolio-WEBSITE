## ✨ Features

- **Material 3, implemented with tokens.** Color roles, typescale, shape scale, elevation, state layers and motion values follow the official `md.sys.*` tokens from Google's Material Web.
- **Material You dynamic color.** Five seed palettes (violet, blue, green, orange, rose), each generated by Google's [Material Color Utilities](https://github.com/material-foundation/material-color-utilities) for both light and dark. Visitors choose a palette and a theme (System / Light / Dark), and the site remembers their choice.
- **M3 Expressive.** Shapes such as cookie, sunny and clover, spring-based motion (CSS `linear()` springs), buttons that morph their shape when pressed, ripples, and an emphasized-easing scroll reveal.
- **Adaptive layout (window size classes).** Compact and medium widths use a top app bar plus a bottom navigation bar. Expanded widths (≥ 840px) switch to a navigation rail. Project details open as a full-screen dialog on phones and a centered dialog on larger screens.
- **Accessible.** Native `<dialog>` handles focus trapping, Esc to close and the inert background. Cards are keyboard-operable, and the page includes a skip link, visible focus rings, `aria-current` navigation and a `prefers-reduced-motion` fallback.
- **Bilingual with full RTL.** Every string lives in `data.json`, and switching language mirrors the layout.
- **No build step, no framework.** Plain HTML, CSS and JS. There's no Tailwind CDN or bundler.
- **SEO.** The main content is in the static HTML. The page also has JSON-LD (`Person`), Open Graph and Twitter cards, and a correct canonical URL.

## 🛠️ Make it yours

### 1. Edit `data.json`
All content lives in one file, split by language (`en`, `ar`):

```json
{
  "en": {
    "personal_info": { "name": "...", "title": "...", "tagline": "...", "links": { ... } },
    "ui":            { "nav_about": "About", "hero_status": "Available for hire", ... },
    "skills":        { "categories": { "languages": "Languages", ... }, "languages": [ ... ] },
    "projects":      [ { "name": "...", "type": "...", "description": "...", "image": "...", "link": "...", ... } ]
  },
  "ar": { ... }
}
```

- A link set to `"#"` is hidden automatically.
- The first project is shown as the featured, full-width card.
- The hero stats (projects, live projects, technologies) are computed from the data.
- The static English text in `index.html` is used for SEO and is replaced at runtime from `data.json`. If you change your name or title, update the `<head>` meta and JSON-LD as well.

### 2. Edit your links page (`/links`)
`links.html` is a link-in-bio page (like Linktree) for your social media profiles. Its buttons come from the top-level `links` array in `data.json`:

```json
"links": [
  { "icon": "youtube", "url": "https://youtube.com/@you", "title": "YouTube",
    "subtitle": { "en": "Long-form videos", "ar": "فيديوهات طويلة" }, "featured": false }
]
```

- The list order in the file is the order on the page. A link set to `"#"` is hidden.
- `title` and `subtitle` can be a plain string or `{ "en": "...", "ar": "..." }`.
- `featured: true` highlights a button with the primary color.
- `icon` is a brand logo (`youtube`, `tiktok`, `instagram`, `facebook`, `linkedin`, `github`, `twitter`, `whatsapp`, `telegram`) or one of the Material Symbols loaded in `links.html` (`work`, `mail`, `link`, `play_circle`, `podcasts`, `article`, `shopping_bag`, `storefront`, `school`, `calendar_month`, `campaign`, `chat`, `call`, `mic`, `videocam`, `download`, `star`, `favorite`, `code`, `language`). An unknown name shows a generic link icon.
- The page title, role and bio come from the `links_*` keys under `ui`.

### 3. Change the color palettes (optional)
Colors are generated from seed colors into `theme.css`:

```bash
cd tools/theme
npm install
npm run build      # regenerates ../../theme.css
```

Edit `SEEDS` in `tools/theme/generate-theme.mjs`. The first seed is the default. If you rename seeds, update the swatches in `index.html` and `SEEDS` in `script.js`.

### 4. Social preview
Replace `og-image.jpg` (1200×630) with a screenshot of your site.

### 5. Deploy
Import the repository into Vercel, Netlify or any static host. There is no build step. `vercel.json` turns on `cleanUrls`, so the links page is served at `/links`.

## 📂 Project structure

```text
├── index.html                # Semantic markup (rail, app bar, sections, dialogs)
├── style.css                 # M3 tokens, typescale, components, layouts, motion
├── theme.css                 # Generated M3 color roles (5 seeds × light/dark)
├── script.js                 # Rendering, i18n, theme/palette, dialogs, ripple, reveal
├── data.json                 # ⚠️ All portfolio content (EN + AR) and the /links list
├── links.html / links.css / links.js  # Link-in-bio page (/links)
├── tools/theme/              # Color scheme generator (Material Color Utilities)
├── avatar-720.webp           # Optimized avatar (avatar.webp is the original)
├── favicon.png, apple-touch-icon.png
├── og-image.jpg              # Social sharing preview
└── vercel.json / _headers    # Security + caching headers
```
